Good morning/Good evening everyone. Today we’ll walk through the Optum AI Codex Skills. 

This session is presented by Prakhar, Amit, and me, Sudhanshu. The main idea is to make Codex more useful for Optum teams through reusable, structured skills that understand our workflows, documentation, coding standards, and common tasks. 

Slide 2 

To start, the core problem we are addressing is the duplication of efforts 

Across teams, we often rebuild the same things: prompts, helper scripts, coding patterns, documentation flows, authentication examples, Dockerfiles, and deployment guidance. A centralized skills repository gives us one shared place to discover, reuse, improve, and share these capabilities. 

This means developers spend less time starting from scratch, business teams get faster and more consistent outcomes, and leadership gets a scalable way to improve productivity and knowledge sharing. 

This will also help boost Codex adoption within the organisation, because teams will have practical, reusable skills that directly support their day-to-day work. 

Slide 3 

Now let’s look at one example: Knowledge Base Skill for HCP. 

This skill makes Codex a single destination for Optum-specific questions by integrating HCP documentation directly into the development workflow. Instead of switching tools or manually searching docs, users can ask questions while they continue building or debugging. 

The skill guides Codex on what references to read, when to search live HCP docs, and how to return optimized, relevant results quickly and efficiently. 

Slide 4 

This slide shows how the Optum Helper Docs skill works. 

When a user asks an Optum or HCP-related question, Codex reads the bundled references, and uses live HCP search when specific guidance is needed. 

It then returns practical answers with relevant links, while ensuring credentials like cookies or session values are never exposed. This keeps developers in flow with trusted Optum documentation context.
